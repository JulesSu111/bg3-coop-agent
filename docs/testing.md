# 测试

## 自动测试

```bash
uv run pytest
```

`tests/fakegame.py` 模拟游戏的调试端口，用 lupa 运行注入的 Lua，`tests/mock_env.lua` 提供假的 `Osi` 和 `Ext`。不需要游戏。GitHub Actions 在 `windows-latest` 上运行同样的测试。

## 实机回归清单

每次改动 Lua 或工具后，在游戏里按下面走一遍。先运行 `bg3coop doctor`，全部 OK 再开始。

测试环境记录：游戏版本、Script Extender 版本（doctor 会显示）、存档地点。

### 开局和读档

- [ ] `party` 列出队伍，人类主角标 `human`
- [ ] 中文版游戏里 `set_agent("Shadowheart")` 也能接管影心
- [ ] `set_agent` 接管队友并解除链接；`regroup` 重新链接，再 `set_agent` 能再次解除
- [ ] 人类选中别的角色（包括 agent 的角色）时，`status` 里的人类仍是原主角；选中 agent 角色时有 `note` 提示
- [ ] 读档后任意工具都能用（自动重新注入），仍然控制同一名队友；`wait` 里 `agent_set` 只出现一次
- [ ] 主菜单或加载中调用工具，返回 `no save is loaded yet`

### 主角接管（待实机验证）

用手动准备的测试存档，记录游戏版本、Script Extender 版本、语言和联机角色归属。测试结束后关闭接管并退出测试存档。

- [ ] 默认使用队友模式。尝试通过 MCP `set_agent` 接管本地主角，分别省略和伪造 `human` 参数，两次都应失败。普通同伴仍可接管、跟随和重新组队。
- [ ] 先接管队友，再选中该队友，用 F10 主角页签启用。核对接管的是本地主角，原队友的反应设置和原组队链接恢复。启用后保持等待，直到玩家点击自由探索才开始行动。
- [ ] 自由探索期间沿可见路线移动，使用普通物体，主动和 NPC 搭话。核对工具报告的任务、台词和选项与屏幕一致，普通回答可以自动推进。对可能攻击、导致离队或承诺阵营的选项，测试拒绝、同意和确认期间选项变化三种情况。
- [ ] 选一项常规技能检定，核对原生骰子动画、点数、总值和剧情结果。切换到其他角色的对话或等待不同骰子窗口，工具应拒绝操作。若版本无法读到骰子归属，记录界面和日志，确认由玩家手动掷骰。
- [ ] 在 AI 移动时分别执行 Pause、Stop、Wait 和 `/protagonist off`。检查动作停止、撤权后无法继续。用 Resume 回到等待，再用自由探索恢复已授权的角色；关闭接管后需要重新启用。玩家应先暂停再手动输入。
- [ ] 在移动和等待剧情确认时分别测试读档、重启游戏、断开本地控制器并重连。授权不能自动恢复，旧动作和确认不能继续。硬退出控制器时检查约一个心跳有效期后移动停止。
- [ ] 在双人联机测试存档中，验证本地主角可以授权；远端玩家的主角和分配给远端玩家的同伴都不能经 MCP 接管。授权身份不应随本地选中角色变化。
- [ ] 核对主角模式拒绝自跟随、交易、传送和反应设置变更。进入一场可控战斗检查行动方与回合，随后切回普通队友检查传送、交易及物品转移。

### 观察

- [ ] `status`：HP、位置、资源、人类的距离和方向
- [ ] `look`：返回 `sight_m: 22`；人类主角总在列表里，看不见时标 `out of sight`；每样东西一行字
- [ ] 原地再 `look`：只剩人类那行，其余算进 `unchanged`，`explore` 是 `as in your last look`；走几步后变化的、新出现的列出，走远的进 `gone`，`explore` 更新；`full=true` 全列；再 `set_agent` 后第一次全列
- [ ] `look` 的 `explore`：地图名、最近的传送点（未解锁的标出）；`unexplored` 至多 3 个坐标，带方向、路程、经过的门（双开门只写一次）、上下几米；`move` 到其中一个能走到；到了以后那里不再列出，换成更远的；人类走过的地方也算；墙后、锁门后、悬崖外的不列；刚到新位置第一次 look 可能带 `more`，再看一次补全；冷启动 Lua 耗时不超过约 250 毫秒（`C.frontCache = {}` 后计时）
- [ ] `look` 的出口：门、楼梯、梯子标 `unexplored beyond`（门后没去过）、`leads up/down N m`（楼梯、梯子）、走不到时 `can't get there: …`（锁门写出是哪扇）；走过去之后 `unexplored beyond` 消失
- [ ] 任务标记：`quests` 有 `markers`（任务目标的名字、距离方向、坐标、对应任务），`look` 的 `explore.quest_marker` 是最近的那个；不打开地图也有；读档后和日志一致
- [ ] 装了 Memory mod（doctor 显示 `mod is loaded`）：没连 agent 时走一段再存档，连上后这段算去过；读回更早的存档，之后走的地方又算没去过；换一个周目的存档，记录不混。没装 mod 时 `explore.memory` 注明只记到下次读档
- [ ] `set_agent` 接管起源队友时有 `role_play`（影心、卡菈克、明萨拉…），自建角色没有
- [ ] `notes`：`set_agent` 结果里带笔记；加 goal 和 persona 笔记后存档、读回更早的存档，goal 消失、persona 还在；再读新档 goal 回来；mod 是 v1 或没装时有 `warning`；新开一局（序章）是新的周目，persona 不串
- [ ] `quests`：列出的任务和游戏任务日志里「进行中」一致（隐藏任务不出现），子任务带 `part_of`，`latest` 是日志里最新那条（文字是游戏语言）
- [ ] `spells`：每个行动一行字（id、名字、种类、消耗、射程、`upcast`、`variants`），只列已准备的法术，现在用不了的带 `NOT NOW: 原因`；`kind` 过滤有效（行里显示的 damage、healing、debuff 也能用）
- [ ] `prepare`：不带参数按职业列出已准备数/上限（和法术书界面一致）、已准备和未准备的法术；只加不减超过上限被拒绝；一换一后 `spells` 跟着变、法术书界面也变；战斗中被拒绝。测完换回
- [ ] `examine`：等级、AC、属性值、抗性/免疫/易伤（卡菈克火焰抗性、矮人毒素抗性）、状态免疫、被动特性（不含隐藏和开关类）和游戏检视窗口一致；看不见的角色和物品被拒绝

### 行动

- [ ] `move`：按方向、`to_human`、按目标；远距离（70 米以上）能走到；走到物体/角色旁边算到达
- [ ] 走不到的地方立刻失败（不再原地等 3 秒）：锁着的门后面（`blocked_by` 是那扇门）、墙里或悬崖外的坐标（`no way there on foot`），都有 `nearest`，按它的坐标 `move` 能走到
- [ ] 按方向走：前面有墙时停在墙前，不会绕出门去；那个方向全是墙时报 `nowhere to walk`
- [ ] `regroup` 之后 `move`/`use`：走到后不会被拉回人类身边，结果有 `unchained`；再 `regroup` 能链回
- [ ] `use`：开关门、开箱子，`effect` 和实际一致
- [ ] `use` 触发别的事：坐长椅开始心灵绘图（`dialogue: true`，对话 `yours: true`，`choose` 能选）；秘密阶梯这类传送（`moved_m`，「taken somewhere else」）；拉杆让附近冒出新东西（`appeared`）。不再报「no visible change」
- [ ] `container`：空容器返回 `items: []`；距离过远会提示
- [ ] `take`：拿到物品（返回任务结果 `taken`）；拿有主物品（或有主容器里的）不带 `steal` 被拒绝；带 `steal` 但没潜行被拒绝，物品没动；潜行后带 `steal` 能拿；有人看着时偷会触发犯罪对话（`dialogue_started`，旁白给出交出/不交/攻击）
- [ ] 对活着的 NPC `container` 和拿他身上的东西都被拒绝（`pockets`），尸体能搜
- [ ] `look` 里橱柜、书桌这类容器标 `container`
- [ ] `look`：40 米内隔着墙的东西也列出（关着的门、隔壁房间的人和物品），潜行的人除外；门窗全关、人类和 agent 都不在里面的房间，里面的东西不列，开一扇门就又列出
- [ ] `look`：物品多的地方约 30 行，同名小东西合并成「x N」一行，其余在 `farther` 里按方向汇总
- [ ] `stop`：停下当前动作
- [ ] `say`：消息出现在聊天面板；面板被 `F10` 隐藏或收起成标题栏时会自动打开并展开；`urgent` 同时弹窗，一分钟内第二次 `urgent` 被拒绝
- [ ] `ask`：面板里出现问题和 Yes/No 按钮（面板隐藏或收起时同样自动打开）；点按钮返回 `answer`，打字返回 `reply`，超时返回 `timed_out` 并在面板注明；按钮随后消失

### 潜行

测完 `sneak(on=false)`，走回人类身边。

- [ ] `sight`：附近活着的人每人一行（朝向、视野锥、`SEES YOU`），死人、队友、看不见的人不列；`seen_by` 和画面一致；`safe_spots` 的点用 `sight(x,y,z)` 查是 `seen_there: false`；墙后的人标 `behind cover`
- [ ] `sneak`：有人看着时被拒绝并点名；没人看着时开启，`status` 和 `wait` 带 `sneaking`，游戏里角色蹲下；`sneak(on=false)` 解除且不产生 `stealth_lost`
- [ ] `move(sneak=true)`：没潜行时被拒绝；会穿过视野锥的路线出发前被拒绝（`seen_at`、`would_see_you`），角色没动；安全路线走完仍在潜行；NPC 转向或角色走近视野锥时在锥外停下（`interrupted`）
- [ ] `even_if_seen` 走进视野锥：被发现后任务 `failed`（`seen_by`），`wait` 收到 `stealth_lost`
- [ ] 战斗中 `sneak`：只在自己回合，扣动作（有附赠隐匿时扣附赠动作）

### 物品

测完把用掉的物品补回（`Osi.TemplateAddTo(模板, 角色, 数量, 0)`），给出的物品拿回来。

- [ ] `inventory`：每件一行（id、名字、`xN`、种类、`heals`、部位）；默认只列药水、卷轴、投掷物，其余只在 `not_shown` 里计数；`kind` 过滤有效；同一叠物品的 `count` 和游戏界面一致；`equipped` 列出身上装备
- [ ] `use_item` 药水：数量减一，`gained` 有对应状态；战斗中只在自己回合、扣附赠动作
- [ ] `use_item` 卷轴：法术生效，卷轴消失，不扣法术位；战斗中扣动作
- [ ] `throw`：背包里的投掷物扔向坐标或角色，数量减一；扔地上看得见的物品；身上穿的护甲被游戏拒绝（`would not throw`）；`use_item` 投掷物时提示用 `throw`
- [ ] `throw` 手雷类（油脂瓶、炼金火焰、闪光弹）落点附近有队友时被拒绝并列出名字，`even_if_allies` 能扔；炉光炸弹不拦；扔远处不拦
- [ ] `use_item` 复活卷轴（回生术）：不给目标时报错；对活着的队友拒绝（`not dead or downed`）、卷轴不消耗；x/y/z 超过 9 米被拒绝；对死亡或倒地的队友复活（1 HP、「复活中」状态），卷轴少一张
- [ ] `equip`：换上后 `equipped: true`，原来那件回到背包；`remove` 能脱下；战斗中被拒绝
- [ ] `give`：整叠交给人类；身上穿着的被拒绝；战斗中被拒绝

### 交易

找一个便宜商人（下城区的鲁格有羽毛笔、奶酪），买了再卖回去，测完人类的金币只少几枚。

- [ ] 第一次 `trade` 在聊天面板问两个问题：能不能交易（带上 `why`）、要不要一起交易；答「否」时 `declined`，窗口不开；10 分钟内同一个商人不再问
- [ ] 自己交易（第二问答「否」）：人类屏幕上看不到交易窗口，技能栏、头像、小地图一直在（留意窗口是否闪一下）；交易期间人类能不能照常点地面走路、按快捷键；买卖完窗口关掉；聊天面板出现「和…交易完了」
- [ ] 一起交易（第二问答「是」）：窗口在人类屏幕上打开并一直开着，agent 买卖时人类能看到；`done=true` 关掉
- [ ] 买卖一叠里的几件（`e12:2`）：游戏的分叠窗口被自动填好，金币和数量对得上；卖背包里已和同类合成一叠的物品也能找到
- [ ] 人类自己开着交易窗口时，agent 的 `trade` 被拒绝；人类在对话里时被拒绝；战斗中被拒绝

### 聊天面板

- [ ] 第一次调用工具后出现「BG3 Co-op (F10)」小窗，有一行提示；`F10` 能开关
- [ ] 消息多到要滚动时，新消息（agent 的、自己打的、`ask` 的回答）出来后日志自动滚到最底下，最后一行完整可见；没有新消息时能往上翻看旧消息
- [ ] 鼠标指着 NPC、物品、地面各按一次 `F9`：面板出现一行灰字，下一个工具结果的 `human_says` 里有 `[pointing at] 名字 (eN, 关系, 距离方向)` 或地面坐标；`F9` 不触发游戏自己的功能；鼠标在面板上时按 `F9` 的结果
- [ ] 标题栏是「BG3 合作 · 角色名 · F10」；`say`/`ask` 后标题栏闪约 3 秒，然后保持金色「N 条新消息」；鼠标移到面板上、点输入框、发消息或按 `F10` 打开后恢复。人类自己发的消息不算新消息。改标题后窗口位置和大小不变（`###bg3coop`）
- [ ] 标题下一行动态：工具运行时「动作 · N 秒」秒数在走（`wait`、长 `move` 时看得到）；工具之间「思考中 · N 秒 · 上一步：…」；两分钟没动作提示可能停下了；带目标的动作显示目标名字
- [ ] 战斗中轮到 agent：agent 还没调用工具时显示「轮到X了 · 还没收到（N 秒）」（红），收到 `your_turn` 后变成「X的回合 · 已收到」（绿）；`end_turn` 后这一行消失
- [ ] 共享回合（人类、agent 等先攻相邻）轮到 agent：agent 在 `wait` 里一两秒内就返回并带 `your_turn`；agent `end_turn` 后、组里其他人还没结束时不会再收到一次 `your_turn`；下一轮又能收到
- [ ] 「动作记录」页：最多 30 条，最新的在最下面并自动滚到底，失败的标红「失败」
- [ ] 聊天页：同一个人连续的消息只在第一条上方显示名字和时间；输入框和快捷按钮完整可见、没被裁掉（不同分辨率下看一次）；回车发送后光标留在输入框
- [ ] 四个快捷按钮点了之后，下一个工具结果里有 `[button] ...`
- [ ] 游戏语言是简体中文时，面板标题、页签、按钮、提示、是/否、动态行都是中文且字能正常显示，agent 收到的 `[button] ...` 仍是英文；其他语言时全是英文
- [ ] 输入框打字、回车或点 Send 发送，下一个工具结果里有 `human_says`；`wait` 收到消息立刻返回
- [ ] 读档后面板重新出现，之前的聊天记录还在
- [ ] 在输入框里打字时，WASD 等按键不会移动镜头或触发游戏快捷键；全屏下也能显示

### 营地

- [ ] `travel camp`：只有 agent 进营地，人类的队伍留在原地（先 `regroup` 链上人类再测）；再调用一次离开营地，回到原处
- [ ] 人类的队伍也在营地时，agent 离开营地不会把他们一起送出去
- [ ] 战斗中、对话中、营地夜晚被拒绝
- [ ] `travel waypoint`：不带名字列出当前地图已解锁的传送点（由近到远）；带名字传送过去，人类的队伍留在原地
- [ ] `dialogue`：列出说话人、台词、编号选项；agent 发起的对话 `yours: true`
- [ ] `choose`：能推进 agent 的对话；人类发起的对话 `yours: false`，`choose` 拒绝
- [ ] `dialogue` 的 `said`：NPC 连说几句时，中间的台词都在 `said` 里（每句只出现一次，带说话人；对话框先出、History 后补的也只记一次）；agent 自己选的回答显示成 agent 的名字（不是人类角色的）；只说一句就结束的 NPC，对话关掉后 `dialogue` 仍能读到那句
- [ ] `choose(why=...)`：聊天面板出现「[选择] 选项 —— 理由」
- [ ] 带检定的选项显示为「[说服] …」「[调查] …」（不是 `[H…]` 句柄）；选了之后 `dialogue` 有 `roll`（技能、DC、`need` 骰面要几、`waiting`，有神导术时 `your_boosts`），`roll` 掷骰（人类屏幕上能看到骰子）并返回点数、总数和成败（总数 ≥ DC 才成功），`reroll_if_failed` 失败时用激励骰重掷，`use_boosts` 先加神导术，对话按结果继续；人类自己的对话里 `roll` 被拒绝

### 战斗

- [ ] `wait` 收到 `combat_started`、`your_turn`、`attacked`
- [ ] 每场战斗开头那条结果（随 `combat_started`，没收到就随第一个 `your_turn`）带 `combat_basics`（bg3.wiki 的战斗规则），同一场战斗只带一次，下一场再带
- [ ] `combat`（和 `your_turn`）每人一行带 x/y/z 和 `walk X m`（走到他身边要的移动力，自己回合标 within/beyond your movement），走不到的写 `no way there on foot`；按这个坐标对地面施放能放出去；`examine` 有 `pos` 和 `walk_m`
- [ ] 战斗结束（打赢，或 agent 逃离而别人还在打）后，正在跑的 `wait` 马上带 `combat_ended` 返回，只一次
